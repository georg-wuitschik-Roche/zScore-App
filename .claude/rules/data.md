# Data Processing Conventions

## Data Flow
```
Two-phase load:
  1. Dropdown index (~12KB JSON) → instant UI   (fetchDropdownIndex)
  2. Parquet (~0.5MB)            → background    (fetchParquetBuffer → parseDataset)

Runtime:
  useEffectiveDataset → useSplitFilteredData → filterChain → plots/stats
```

## Filter Chain
All filtering goes through `filterChain.ts`. Filters apply in a specific order (cheap first). Never add ad-hoc filtering in components.

```ts
// Good - use the filter chain via hook
const panels = useSplitFilteredData()

// Bad - filtering in components
const result = data.filter(row => row.Base === "Et3N")
```

## Split Mode
When a filter has 2+ selected values, it can be "split" into side-by-side panels. `useSplitFilteredData` runs the filter chain once per split value — the split dimension is pinned to one value per panel while other filters stay the same. This means the filter chain runs N times for N split values.

## Zustand Store
- Single store in `filterStore.ts` — data, filters, UI, versions, comparison, upload
- Named selectors for each piece of state — never `useFilterStore()` with full state
- Actions are methods on the store, not external functions
- `setReactionTypes()` clears dependent state (fgA, fgB, split)
- `DEFAULTS` in `types.ts` is the single source of truth for filter defaults

## Effective Dataset
`useEffectiveDataset` resolves which data the app operates on:
- No upload → built-in dataset
- Upload in 'replace' mode → uploaded data only
- Upload in 'combine' mode → `[...dataset, ...uploadedDataset]`

## CSV Upload
- Parsed with PapaParse in `loader.ts` (auto-detects comma/semicolon/tab delimiters)
- Validated against `REQUIRED_COLUMNS` from `types.ts`
- In combine mode, ELN_IDs are prefixed with `upload_` to avoid collisions
- Persisted to localStorage via `uploadStorage.ts` (handles QuotaExceededError)

## Version Comparison
- `comparison.ts`: `computeRankDeltas()` groups by reactant type, ranks by median z-Score
- `useComparisonData.ts`: runs filter chain on comparison dataset, computes rank deltas per panel
- Positive `rankChange` = moved up, negative = moved down, `isNew` = not in comparison
- Version manifest auto-generated by `vite-plugin-versions.ts`

## Data Loader (`loader.ts`)
- `cleanRow()` normalizes each raw row: BigInt → number, empty/NaN → null, decimal comma → period
- `FG_PAIR_SORTED` is computed at load time if missing (sorted pair of FG A + FG B)
- Parquet is ~30x smaller than CSV — chosen for load performance
